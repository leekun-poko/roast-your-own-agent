One original roast of a generic AI agent, in a single line: asked for a yes or no, it answers with six bullet points, two subheadings, and a summary of the bullet points. Running the program writes that line to /output/entry.txt (or to $MAKEFUN_OUTPUT_DIR/entry.txt when the variable is set).

## Run it

```sh
python3 main.py
```
